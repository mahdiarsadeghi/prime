# Prime-number explorations

This repository collects small computational and expository explorations of prime numbers. It is a place to document open questions, test simple experiments, and share mathematical curiosities.

## Current contents

- `open problems/computational/` — notes and computational directions for open problems
- `goldbach_strong_conjecture.md` — a starting point for exploring Goldbach’s strong conjecture

The project is intentionally lightweight: each addition should explain the question, the method used, and what the computation can and cannot show.
